# Ootday Pelanggan

A premium Flutter application for fashion enthusiasts.

## Compatibility Note
This project is configured to be compatible with:
- **Flutter**: 3.27.2+
- **Dart SDK**: ^3.6.1

## Features
- ✨ Premium UI with Glassmorphism effects
- 🎨 Modern Dark Theme (Slate & Indigo)
- 🏃 Smooth Animations with `flutter_animate`
- 📍 Icons by `Iconsax`
- 🅰️ Typography by `Google Fonts (Outfit)`
